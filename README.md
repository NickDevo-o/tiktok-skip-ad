## ⚡ Особенности работы

- 🎯 **Без пропуска видео целиком:** Ролик не перелистывается и не блокируется. Перематывается **только рекламная вставка** (+4..+5 секунд вперед) прямо по таймлайну TikTok, после чего воспроизведение контента продолжается.
- 👁 **Визуальное распознавание (Без опоры на хештеги):** Авторы часто не указывают хештеги спонсоров в описании. Сервис сканирует кадры видео через оффлайн-модель нейросети **Google ML Kit Text Recognition** 2 раза в секунду (каждые 500 мс).
- 🎛 **Гибкие настройки перемотки:** Возможность выбрать комфортный шаг перемотки (~3 сек, ~5 сек или ~8 сек), а также включить или выключить всплывающие Toast-уведомления (тихий режим).
- ➕ **Свои фильтры и сайты:** Добавляйте любые свои ключевые слова и ссылки прямо из интерфейса (например: новые рулетки, казино или промокоды стримеров).
- 📊 **Постоянная статистика:** Подсчёт пропущенных рекламных вставок и сэкономленного времени сохраняется даже после перезагрузки устройства.
- 🔕 **Без навязчивых окон захвата экрана:** Использует нативный `AccessibilityService.takeScreenshot()` (Android 11+), не требующий подтверждения «Показать экран приложению?».
- 🔒 **100% Офлайн и Приватно:** Распознавание работает локально на процессоре смартфона, без отправки скриншотов в сеть и без расхода интернет-трафика.
- 🧩 **Совместимость:** Работает как с официальным клиентом TikTok, так и с популярными модами для РФ (Rezvorck TikTokPlugin, сборки `com.zhiliaoapp.musically`, Lite и др.).

## 🛡️ Безопасность и Приватность (Security & Privacy)

Многие пользователи справедливо с осторожностью относятся к предоставлению разрешений `AccessibilityService` сторонним приложениям. Вот почему **TikTok Case Ad Skipper полностью безопасен**:

1. 🚫 **Полное отсутствие разрешения на интернет (`No INTERNET Permission`):**  
   В `AndroidManifest.xml` приложения **вообще нет** разрешения `android.permission.INTERNET`. Это аппаратная изоляция на уровне ядра Android (Linux Sandbox): приложение физически **не способно отправить ни один байт данных или скриншот во внешнюю сеть**. Вы можете убедиться в этом лично в настройках Android (*«Приложения» → «Разрешения»*).

2. 🧠 **100% Локальная нейросеть (On-Device ML):**  
   Распознавание текста через Google ML Kit работает полностью автономно на процессоре вашего устройства без облачных вычислений.

3. 🔍 **Нулевая телеметрия и отсутствие трекеров:**  
   В коде нет Firebase Analytics, Flurry, Яндекс.Метрики, рекламных баннеров или скрытых SDK сбора информации.

4. 👤 **Безопасность вашего аккаунта TikTok:**  
   Утилита не модифицирует код TikTok, не перехватывает сетевые пакеты и не внедряется в оперативную память. Серверы TikTok видят перемотку как обычный свайп пальцем по экрану от живого человека.

5. 📖 **Открытый исходный код (Open Source):**  
   Весь проект полностью прозрачен. Вы можете изучить каждую строку кода или собрать APK самостоятельно из репозитория.

## 📱 Инструкция по установке

### Вариант 1. Готовый APK (Быстрая установка)
1. Скачайте актуальный файл **`TikTokAdSkipper.apk`** из раздела [Releases](https://github.com/NickDevo-o/tiktok-skip-ad/releases) (или установите через ADB).
2. Запустите приложение на смартфоне.
3. Нажмите кнопку **«Включить службу спец. возможностей»** (Accessibility Service) и предоставьте доступ для **TikTok Ad Skipper**.
4. Нажмите **«Запустить TikTok»**.
5. Готово! Приложение работает в фоне. При появлении рекламы рулеток или кейсов появится короткое уведомление `⏩ Перемотка рекламы...`, и ползунок таймлайна автоматически сдвинется вперед.

### Вариант 2. Сборка из исходников
Для самостоятельной сборки потребуется JDK 17+ и Android SDK:
```bash
git clone https://github.com/NickDevo-o/tiktok-skip-ad.git
cd tiktok-skip-ad
./gradlew assembleDebug
```
Собранный файл будет находиться в:
`app/build/outputs/apk/debug/app-debug.apk`
