# TikTok Case Ad Skipper ⏩

Умный компаньон для Android, автоматически перематывающий встроенную рекламу кейсов, рулеток скинов CS2 и партнерских сетей (таких как **«Мусор Дроп» / Musor Drop, Upgrader, SkinHouse, CSFail** и др.) в TikTok.

## ⚡ Особенности работы

- 🎯 **Без пропуска видео целиком:** Ролик не перелистывается и не блокируется. Перематывается **только рекламная вставка** (+4..+5 секунд вперед) прямо по таймлайну TikTok, после чего воспроизведение контента продолжается.
- 👁 **Визуальное распознавание (Без опоры на хештеги):** Авторы часто не указывают хештеги спонсоров в описании. Сервис сканирует кадры видео через оффлайн-модель нейросети **Google ML Kit Text Recognition** 2 раза в секунду (каждые 500 мс).
- 🔕 **Без навязчивых окон захвата экрана:** Использует нативный `AccessibilityService.takeScreenshot()` (Android 11+), не требующий подтверждения «Показать экран приложению?».
- 🔒 **100% Офлайн и Приватно:** Распознавание работает локально на процессоре смартфона, без отправки скриншотов в сеть и без расхода интернет-трафика.
- 🧩 **Совместимость:** Работает как с официальным клиентом TikTok, так и с популярными модами для РФ (Rezvorck TikTokPlugin, сборки `com.zhiliaoapp.musically`, Lite и др.).

## 📱 Инструкция по установке

### Вариант 1. Готовый APK (Быстрая установка)
1. Скачайте актуальный файл **`TikTokAdSkipper.apk`** из раздела [Releases](https://github.com/NickDevo-o/tiktok-skip-ad/releases) (или установите через ADB).
2. Запустите приложение на смартфоне.
3. Нажмите кнопку **«Включить службу спец. возможностей»** (Accessibility Service) и предоставьте доступ для **TikTok Ad Skipper**.
4. Нажмите **«Запустить TikTok»**.
5. Готово! Приложение работает в фоне. При появлении рекламы рулеток или кейсов появится короткое уведомление `⏩ Перемотка рекламы...`, и ползунок таймлайна автоматически сдвинется вперед.

### Вариант 2. Сборка из исходников
Для самостоятельной сборки потребуется JDK 17+ и Android SDK:
```bash
git clone https://github.com/NickDevo-o/tiktok-skip-ad.git
cd tiktok-skip-ad
./gradlew assembleDebug
```
Собранный файл будет находиться в:
`app/build/outputs/apk/debug/app-debug.apk`

- **Язык:** Kotlin + Coroutines

- **ML / Компьютерное зрение:** Google ML Kit Vision Text Recognition (Latin & Cyrillic)
- **Автоматизация жестов:** Android AccessibilityService (`dispatchGesture`, `takeScreenshot`)
